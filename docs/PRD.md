# PipeSched PRD（v1 边界）

## 一句话

在开源制作跟踪 Kitsu 旁路做「模板化排期建议 + 规则风险卡」，日期和工时不让模型填，写回必须制片确认。

## 用户

制片 / 项目管理（主用户），主美和外包协调旁观。

## 做

- 两套 YAML 模板：手游短管线、角色全流程。换模板不改代码。
- 同类已完成任务检索估时（中位数 / P75），不足则模板默认并标低置信。
- 在 DAG、工作日历和周产能下给出建议 `start_date` / `due_date`。
- 规则风险：逾期、超估、高返修、依赖阻塞、评审 SLA。影子模式出卡，不改状态。
- 可选 LLM 解读备注并强制引用原文；无 key 时规则 + 关键词基线仍可用。
- 确认写回与审计日志。无确认令牌代码层拒绝。

## 明确不做（v1）

- 多人多技能资源优化排程、自动改派、自动改状态。
- 和真实外包系统打通。
- 复杂节假日日历（只跳周末和模板里的 holidays）。
- 把 Kitsu 官方任务跟踪说成自己实现的。

## 何时不用 AI

日期、实耗、返修、状态只来自 Gazu / Zou。没有历史时不用假装精确。LLM 挂了规则仍转。评论涉及人事不做自动广播。
